# Exercícios de Python

Uma coleção de exercícios práticos para aprender os fundamentos de Python: entrada e saída de dados, variáveis, operadores, condicionais, listas e laços de repetição. O repositório reúne pequenos programas de terminal e notebooks Jupyter, cada um independente e fácil de explorar.

## Conteúdo

| Arquivo | O que você vai praticar |
| --- | --- |
| [`fizzbuzz.py`](./fizzbuzz.py) | Laços, intervalos e condições com FizzBuzz |
| [`jokenpo.py`](./jokenpo.py) | Entradas do usuário e lógica de um jogo de pedra, papel e tesoura |
| [`logicos.py`](./logicos.py) | Comparações e estruturas condicionais |
| [`operadores.py`](./operadores.py) | Operações matemáticas, resto, potência e raiz |
| [`produtos.py`](./produtos.py) | Listas, preços, cadastro e formatação de valores |
| [`python.py`](./python.py) | Listas e associação de produtos a valores |
| [`revisao.py`](./revisao.py) | Primeiros passos com `print` e variáveis |
| [`atividade1.ipynb`](./atividade1.ipynb) | Atividade interativa com listas de produtos e preços |
| [`cadastro.ipynb`](./cadastro.ipynb) | Coleta e exibição de dados de cadastro |
| [`casa.txt`](./casa.txt) | Lista de etapas para construir uma casa |

## Requisitos

- Python 3 instalado para executar os arquivos `.py`.
- Jupyter Notebook ou JupyterLab para abrir os arquivos `.ipynb`.

Os exercícios não exigem bibliotecas externas para os exemplos em Python.

## Como começar

1. Clone ou baixe este repositório.
2. Abra um terminal na pasta do projeto.
3. Execute um exercício:

   ```bash
   python fizzbuzz.py
   ```

   Em alguns sistemas, o comando pode ser `python3`:

   ```bash
   python3 fizzbuzz.py
   ```

Cada script pode ser executado separadamente. Alguns deles pedem informações pelo terminal; siga as instruções exibidas na tela.

### Abrir os notebooks

Com Jupyter instalado, inicie-o na pasta do projeto:

```bash
jupyter notebook
```

Depois, abra `atividade1.ipynb` ou `cadastro.ipynb` pela interface e execute as células em ordem.

## Objetivo de aprendizagem

Este projeto serve como espaço de prática e revisão. Experimente alterar os valores, testar diferentes entradas e adicionar novas regras aos exercícios para observar como cada conceito funciona.
